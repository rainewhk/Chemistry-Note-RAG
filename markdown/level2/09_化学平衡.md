# 01 · 化学平衡状态 <Badge type="warning" text="整理中" />

## 可逆反应

### 概念

在相同条件下，既能向正反应方向进行，同时又能向逆反应方向进行的化学反应。

在化学方程式中用 $\xrightleftharpoons{}$ 表示。

### 特征

1. 双向性：可逆反应包含方向相反的正反应和逆反应。
2. 双同性：在同一条件下，正、逆反应同时进行。
3. 共存性：反应物转化率小于 $100\%$，反应物与生成物共存。

## 化学平衡状态

### 概念

在一定条件下，可逆反应体系中，当正、逆反应速率相等，且反应物和生成物浓度保持不变时，体系组成不再随时间改变，此时称为化学平衡状态。

<img alt="化学平衡-1.1" src="/09 化学平衡/images/1.1.svg"/>

### 平衡建立过程

1. 反应开始时：反应物浓度最大，$v(\text{正})$ 最大；生成物浓度为 $0$，$v(\text{逆})=0$。
2. 反应进行时：反应物浓度降低，$v(\text{正})$ 减小；生成物浓度增大，$v(\text{逆})$ 增大。
3. 达到平衡时：$v(\text{正})=v(\text{逆})\neq0$，各组分浓度保持不变。

### 特征

1. 研究对象：可逆反应。
2. 动态平衡：$v(\text{正})=v(\text{逆})\neq0$。
3. 浓度不变：各组分浓度、百分含量保持不变。
4. 条件依存：外界条件变化后会建立新平衡。

## 化学平衡状态判断

以 $m\ce{A}_{(g)}+n\ce{B}_{(g)} \xrightleftharpoons{} p\ce{C}_{(g)}+q\ce{D}_{(g)}$ 为例：

### 判断核心

1. 正、逆反应速率之比等于化学计量数之比，且必须体现“一正一逆”。
2. 随反应进行而变化的变量不再变化。

### 具体判断依据

| 类型                              | 判断依据                                                                               | 是否为平衡状态 |
| --------------------------------- | -------------------------------------------------------------------------------------- | -------------- |
| 混合体系中各成分含量              | 各物质的物质的量或物质的量分数一定                                                     | 是             |
|                                   | 各物质的质量或质量分数一定                                                             | 是             |
|                                   | 各气体的体积或体积分数一定                                                             | 是             |
| 正逆反应速率关系                  | 单位时间内消耗 $m\ \text{mol}\ \ce{A}$，同时生成 $m\ \text{mol}\ \ce{A}$               | 是             |
|                                   | 单位时间内消耗 $n\ \text{mol}\ \ce{B}$，同时生成 $p\ \text{mol}\ \ce{C}$               | 否             |
|                                   | $v(\ce{A}):v(\ce{B}):v(\ce{C}):v(\ce{D})=m:n:p:q$                                      | 否             |
|                                   | 单位时间内生成 $n\ \text{mol}\ \ce{B}$，同时消耗 $q\ \text{mol}\ \ce{D}$（同为逆反应） | 否             |

| 气体密度                          | $m+n\ne p+q$，恒温恒压时，密度不变                                                     | 是             |

| 颜色                              | 有色物质颜色一定                                                                       | 是             |
| 绝热条件温度                      | 体系温度不变                                                                           | 是             |
| 绝热条件压强                      | $m+n=p+q$ 时，压强不变                                                                 | 是             |

## 化学平衡常数

### 浓度商 $Q$

1. 定义：任意时刻，生成物浓度幂之积与反应物浓度幂之积的比值。
2. 对于
   $m\ce{A}_{(g)}+n\ce{B}_{(g)} \xrightleftharpoons{} p\ce{C}_{(g)}+q\ce{D}_{(g)}$：

$$
Q=\frac{c^p(\ce{C})\cdot c^q(\ce{D})}{c^m(\ce{A})\cdot c^n(\ce{B})}
$$

### 化学平衡常数 $K$

1. 定义：温度一定时，反应达到平衡状态后，生成物浓度幂之积与反应物浓度幂之积的比值。
2. 表达式：

$$
K=\frac{c^p(\ce{C})\cdot c^q(\ce{D})}{c^m(\ce{A})\cdot c^n(\ce{B})}
$$

固体和纯液体不写入表达式。

3. 意义：$K$ 越大，反应进行越完全，反应物转化率越高。通常 $K>10^5$ 可视为基本完全，$K<10^{-5}$ 反应较难进行。
4. 与方程式关系：
   - 正逆反应的平衡常数互为倒数：$K_{\text{正}}=\frac{1}{K_{\text{逆}}}$。
   - 方程式各系数同乘 $x$，则新平衡常数为原来的 $x$ 次方。
   - 两反应方程式相加，总反应平衡常数等于各自平衡常数乘积：$K_{\text{总}}=K_1\cdot K_2$。
5. 影响因素：只受温度影响，与浓度、压强、催化剂无关。

### 用 $Q$ 与 $K$ 判断反应方向

1. $Q<K$：反应正向进行，$v(\text{正})>v(\text{逆})$。
2. $Q=K$：反应达到平衡，$v(\text{正})=v(\text{逆})$。
3. $Q>K$：反应逆向进行，$v(\text{正})<v(\text{逆})$。

## 化学平衡移动

### 概念与实质

1. 概念：平衡后改变条件，原平衡被破坏，经过一段时间建立新平衡。
2. 实质：条件变化导致 $v(\text{正})\ne v(\text{逆})$，各组分百分含量随之变化。

### 勒夏特列原理

改变影响平衡的条件之一（浓度、压强、温度），平衡将向减弱该改变的方向移动。

### 外界条件对平衡的影响

| 改变条件（其他不变） | 平衡移动方向                   | 说明                                                      |
| -------------------- | ------------------------------ | --------------------------------------------------------- |
| 浓度                 | 增大反应物浓度或减小生成物浓度 | 正向移动                                                  |
|                      | 减小反应物浓度或增大生成物浓度 | 逆向移动                                                  |
| 压强（有气体参与）   | $m+n\ne p+q$，增大压强         | 向气体分子数减小方向移动                                  |
|                      | $m+n\ne p+q$，减小压强         | 向气体分子数增大方向移动                                  |
|                      | $m+n=p+q$，改变压强            | 平衡不移动                                                |
| 温度                 | 升高温度                       | 向吸热反应方向移动                                        |
|                      | 降低温度                       | 向放热反应方向移动                                        |
| 催化剂               | 加入催化剂                     | 平衡不移动（同等程度改变 $v(\text{正})$、$v(\text{逆})$） |

### 惰性气体影响

1. 恒温恒容：充入惰性气体后总压强增大，但各组分浓度不变，平衡不移动。
2. 恒温恒压：充入惰性气体后容器体积增大，各组分浓度同倍数减小，等效于减压，平衡按减压规律移动。

## 等效平衡

### 定义

同一可逆反应在一定条件（恒温恒容或恒温恒压）下，采用不同投料方式达到平衡时，若相同组分的百分含量（体积分数、物质的量分数、质量分数）相等，则称为等效平衡。

### 判断方法

极值转换法（“一边倒”）：将反应物或生成物按计量数完全转化到另一侧，再比较投料关系。

### 分类与结论

1. 恒温恒容：
   - 一边倒后投料量完全相等：平衡时各物质浓度、百分含量均相等。
   - 一边倒后投料量成比例且气体分子数不等：等效于加压或减压，平衡移动，百分含量不同。
   - 一边倒后投料量成比例且气体分子数相等：平衡不移动，百分含量相等。
2. 恒温恒压：
   - 一边倒后投料量完全相等或成比例：都可形成等效平衡，百分含量相等。

### 转化率与热量关系

1. 若两过程为等效平衡且反应方向相反，则转化率之和为 1：$\alpha_1+\alpha_2=1$。
2. 热量关系：$|Q_1|+|Q_2|=|\Delta H|$（$Q$ 为过程放热或吸热，$\Delta H$ 为反应焓变）。

# 02 · 化学平衡常数 <Badge type="warning" text="整理中" />

## 一、浓度商（$Q$）

1. **定义**：在可逆反应的任意时刻（非平衡状态），生成物浓度幂之积与反应物浓度幂之积的比值，称为浓度商。

2. **表达式**：对于可逆反应 $m\mathrm{A}(g) + n\mathrm{B}(g) \rightleftharpoons p\mathrm{C}(g) + q\mathrm{D}(g)$，浓度商表达式为：

   $$
   Q = \frac{c^p(\mathrm{C}) \cdot c^q(\mathrm{D})}{c^m(\mathrm{A}) \cdot c^n(\mathrm{B})}
   $$

3. **注意事项**：
   - 表达式中浓度为任意时刻的瞬时浓度，非平衡浓度。
   - 固体、纯液体的浓度视为常数，不列入浓度商表达式。

## 二、化学平衡常数（$K$）

### （一）定义

温度一定时，可逆反应达到化学平衡状态时，生成物浓度幂之积与反应物浓度幂之积的比值为定值，该定值即为化学平衡常数（简称平衡常数）。

### （二）表达式

1. **通用表达式**：对于可逆反应 $m\mathrm{A}(g) + n\mathrm{B}(g) \rightleftharpoons p\mathrm{C}(g) + q\mathrm{D}(g)$，平衡常数表达式为：

   $$
   K = \frac{c^p(\mathrm{C}) \cdot c^q(\mathrm{D})}{c^m(\mathrm{A}) \cdot c^n(\mathrm{B})}
   $$

2. **特殊情况**：
   - 反应中有固体/纯液体参与时，其浓度视为常数，不列入表达式（如 $\mathrm{CaCO}_3(s) \rightleftharpoons \mathrm{CaO}(s) + \mathrm{CO}_2(g)$，$K = c(\mathrm{CO}_2)$）。
   - 表达式中浓度为平衡时的浓度，单位需与化学计量数匹配。

### （三）单位

平衡常数的单位由反应方程式中各物质的化学计量数决定，无固定值：

- 如 $\mathrm{H}_2(g) + \mathrm{I}_2(g) \rightleftharpoons 2\mathrm{HI}(g)$ 的 $K$ 无单位；
- 如 $\mathrm{N}_2(g) + 3\mathrm{H}_2(g) \rightleftharpoons 2\mathrm{NH}_3(g)$ 的 $K$ 单位为 $(\mathrm{mol \cdot L}^{-1})^{-2}$。

### （四）意义

平衡常数值的大小反映化学反应的进行程度（反应限度）：

- $K > 10^5$：反应基本完全，反应物平衡转化率极高；
- $10^{-5} < K < 10^5$：反应为可逆反应，反应物有一定转化率；
- $K < 10^{-5}$：反应难以发生，反应物转化率极低；
- **注意**：$K$ 仅反映反应限度，与反应速率无关（$K$ 大不代表反应速率快）。

### （五）与化学方程式书写形式的关系

平衡常数与化学方程式的书写形式一一对应，规律如下：

1. **正逆反应**：正反应平衡常数 $K_{\text{正}}$ 与逆反应平衡常数 $K_{\text{逆}}$ 互为倒数，即 $K_{\text{正}} = \dfrac{1}{K_{\text{逆}}}$；
2. **系数缩放**：化学方程式乘以系数 $x$，平衡常数变为原常数的 $x$ 次方，即 $K' = K^x$；
3. **反应叠加**：两个方程式相加得到总方程式，总反应平衡常数等于两分反应平衡常数的乘积，即 $K_{\text{总}} = K_1 \cdot K_2$。

### （六）影响因素

1. **核心影响因素：温度**（平衡常数是温度的函数）：
   - **放热反应**（$\Delta H < 0$）：升温，$K$ 减小；降温，$K$ 增大；
   - **吸热反应**（$\Delta H > 0$）：升温，$K$ 增大；降温，$K$ 减小。

2. **无关因素**：反应物/生成物的浓度（或分压）、压强、催化剂等，只要温度不变，$K$ 始终不变。

### （七）核心应用

1. **判断反应进行方向**：通过比较 $Q$ 与 $K$ 的大小判断：
   - $Q < K$：反应正向进行（$v_{\text{正}} > v_{\text{逆}}$）；
   - $Q = K$：反应达到平衡状态（$v_{\text{正}} = v_{\text{逆}}$）；
   - $Q > K$：反应逆向进行（$v_{\text{正}} < v_{\text{逆}}$）。

2. **计算平衡相关量**：已知 $K$ 和初始浓度，可通过"三段式"计算平衡浓度、反应物转化率等；

3. **比较反应限度**：同一温度下，相同类型的可逆反应，$K$ 越大，反应进行得越完全。

### （八）补充说明

1. **分压平衡常数（$K_p$）**：若反应体系为气体，可采用分压代替浓度计算平衡常数（$K_p$），其数值与 $K$ 不同，但意义一致，且仅受温度影响；

2. **多步反应**：总反应的平衡常数等于各步反应平衡常数的乘积，可通过该规律计算难直接测定的反应的 $K$；

3. **表达式书写**：需明确物质聚集状态，仅气体、溶液中的溶质列入，固体、纯液体除外。

## 电离与水解

### 电离平衡

1. 定义：弱电解质电离与结合的的速率相同，各粒子浓度不变；

2. **注意**：
   1. 电离过程吸热；

   2. 平衡时，转化率极小；

3. **影响因素**：自身性质；温度（$T$ 增大，平衡右移）、浓度（**越稀越电离，但是离子浓度降低**）

4. **比较依据**：$K_a$、$K_b$ 越大，越易电离，越显酸性、碱性。

### 盐类水解

1. **注意**：
   1. 水解吸热；

   2. 水解一般极微弱；

2. **影响因素**：自身因素、**体系温度 $T$**、**溶液浓度 $c$**；

3. **应用**：
   1. 加热 $\ce{Na_2CO_3(aq)}$更容易去污；

   2. 储存、配置易水解的盐加酸；

   3. 可溶性铝/铁盐净水；

   4. 制取 $\ce{TiO_2}$、$\ce{SnO}$、$\ce{SnO_2}$ 等过渡金属氧化物；

   5. 判断溶液酸碱性；

   6. 制备固盐、胶体；

   7. 判断离子是否共存。

## 盐类的酸碱性

1. 强酸强碱盐不水解，呈中性；

2. 弱酸根离子水解产生 $\ce{OH^-}$，弱碱阳离子水解产生 $\ce{H^+}$，因此强酸弱碱盐呈酸性，弱酸强碱盐呈碱性；

3. 弱酸弱碱盐应当看两种离子水解的 $K$，$K_{a}(\text{酸})$ 大（酸性更强）则呈酸性，$K_{b}(\text{碱})$ 大（碱性更强）则呈碱性，相近则中性；

4. 弱酸酸式盐的酸碱性应当比较 $K_a$ 和 $K_h$，$K_h$ 大于 $K_a$，溶液呈碱性，反之呈酸性。

### 强弱酸的判断

1. $0.1$ $mol/L$ 的溶液中，$pH=1$ 的为强酸，$pH>1$ 的为弱酸；

2. 同 $t$ 同 $c$ 的两种酸与金属反映的速率或导电能力；

3. 钠盐的 $pH$。

### 水溶液中的三大守恒

1. 电荷守恒：溶液中所有阳离子所带的正电荷总浓度等于所有阴离子所带的负电荷总浓度；

2. 物料守恒：不同形式的相同元素之和之比是化学式之比；

3. 质子守恒：水电离出的以不同形式存在的 $\ce{H+}$ 和 $\ce{OH-}$ 的量相等。

## pH

$pH=-\lg c(\ce{H+})$；

意义：

1. 常温下，$pH=7$ 为中性，$pH<7$ 为酸性，$pH>7$ 为碱性；

2. $pH$ 越小则越酸，越大则越碱。

### pH试纸

1. 操作：取一小块pH试纸于干燥洁净的玻璃片或表面皿上，用**干燥清洁的玻璃棒蘸取待测液于pH试纸上**，与标准比色卡对准读数；

2. 种类：
   1. 广泛 $pH$ 试纸：测定范围为 $(1,14)$ 或 $(1,10)$，可识别的差距为 $1$；

   2. 精密 $pH$ 试纸：测定范围较窄，差距为 $0.2$ 或 $0.3$；

   3. 专用 $pH$ 试纸：只适用于酸性/碱性/中性溶液；

   **其它检测$pH$的工具**：$pH$ 计/酸度计：精密测量 $pH$，量程 $0-14$.

3. 注意：
   1. $pH$ 试纸本身为黄色，酸红碱蓝；

   2. $pH$ 试纸不能润湿，否则会导致酸性溶液结果偏大，碱性溶液结果偏小；

   3. $pH$ 试纸不能测量有漂白性、脱水性的物质，如**氯气、次氯酸**（但是二氧化硫溶液可以用 $pH$ 试纸测）。

## 沉淀溶解平衡

1. 定义：沉淀（生成）的速率与溶解的速率相等；

2. 移动：一般升温会使平衡正移，但也有例外，例如 $\ce{Ca(OH)_2}$。

**溶解度（$s$）**

1. 定义：一定温度（压强）下，某一物质在 $100$ $g$ 溶液里的质量（体积）；

2. **影响因素**：
   1. 溶质本身与溶剂、溶液的因素；

   2. 一般温度增大，固体的溶解度增加，气体减少；

   3. 一般压强增大，气体的溶解度增大。

### 溶解度大小的比较

1.  阴阳离子之比相同的物质，$K_{sp}$ 越大，溶解度越大；

2.  其他物质应当计算平衡时的浓度；

3.  复分解反应中，溶解性大的生成溶解性小的。

### 沉淀生成

1. 方法：
   1. 调节 $pH$（**如 $\ce{ Fe^{3+} }$ 可以通过通入 $\ce{NH_3}$ 的方式沉淀**）；

   2. 加沉淀剂；

**元素示例**

- $\ce{Ba^{2+}}$、$\ce{Pb^{2+}}$、$\ce{Ca^{2+}}$ 用 $\ce{H_{2}SO_{4} }$ 沉淀。
- $\ce{ Ca^{2+}, Mg^{2+}, F^{-} }$ ($pH$ 不应过低，防止生成 $HF$）。
- $\ce{Cu^{2+}}$、$\ce{Ag+}$、$\ce{Pb^{2+}}$、$\ce{Ni^{2+}}$ 用 $\ce{S^{2-}}$ 沉淀。
- $\ce{Ca^{2+}}$、$\ce{Ba^{2+}}$、$\ce{Fe^{3+}}$、$\ce{Al^{3+}}$ 可用硫酸盐等沉淀剂分别沉淀（与 $\ce{Ca^{2+}}$、$\ce{Ba^{2+}}$ 形成沉淀，与 $\ce{Fe^{3+}}$、$\ce{Al^{3+}}$ 成氢氧化物）。
- $\ce{Ca^{2+}}$、$\ce{Co^{2+}}$、$\ce{Ni^{2+}}$ 可溶性草酸盐。

2. 应用：无机物的制备和提纯、废水处理等；

### 沉淀溶解

1. 原理：对于难溶的电解质，如果能设法不断移取生成物，使平衡向右移动，则可以使沉淀溶解；

2. 方法：
   1. 酸/碱溶解法
      $\ce{V2O5}$ 可以被酸溶解，生成 $\ce{VO2+}$，也可以溶于强碱
      $\ce{Cr2O3}$、$\ce{Cr(OH)3}$ 有两性，遇碱生成 $\ce{[Cr(OH)4]^-}$，遇酸生成 $\ce{Cr^{3+}}$
   2. 盐溶解法；

   3. 生成配合物法
      氨水溶解氢氧化铜：$\ce{Cu(OH)2 +4NH3\cdot H2O \xlongequal{} [Cu(NH3)4]^2+ +2OH- +4H2O}$

   4. 氧化还原法（酸浸不活泼金属时会加入双氧水促进溶解）
      $\ce{Cu +H2O2 +H2SO4 \xlongequal{} CuSO4 +2H2O}$

### 沉淀转化

1. 条件：一般溶解性大的转化为溶解性小的，但有时可以逆向转化；

2. 应用：
   1. 去除水垢；

   2. 化工流程中金属提取。

# 04 · 化学反应进行的方向 <Badge type="warning" text="整理中" />

## 自发过程与自发反应

### 自发过程

1. **定义**：在一定条件下，不需要外力作用就能自动进行的过程。
2. **常见实例**：
   - 室温下冰块自动融化；
   - 水往低处流；
   - 锌与硫酸铜溶液自动反应；
   - 甲烷在氧气中自动燃烧（点燃只是引发条件）。
3. **特点**：
   - 自发过程都有明确的方向性，其逆过程不能自发进行；
   - 自发过程与反应速率无关：自发反应不一定快（如常温下氢氧混合气体可以长期共存）；
   - "自发"说的是**可能性**，实际能否发生还要看条件是否具备。

## 焓判据（能量判据）

1. 放热反应过程中体系能量降低，因此具有自发进行的倾向。
2. 科学家用焓变判断反应进行的方向：
   - $\Delta H < 0$：体系能量降低，反应**倾向于**自发进行；
   - $\Delta H > 0$：体系能量升高，反应**倾向于**不能自发进行。
3. **局限性**：
   - 只能判断"倾向"，不能下绝对结论；
   - 存在大量反例：$\ce{NH4NO3}$ 溶于水吸热但自发；冰融化（$\Delta H>0$）在高于 $0\ ^\circ\mathrm{C}$ 时自发；$\ce{CaCO3}$ 高温分解（$\Delta H>0$）也能自发进行。

> **注意**
> 焓判据只能单独作为参考，不能作为唯一判据——很多吸热过程在特定条件下也是自发的。

## 熵判据（混乱度判据）

### 熵与熵变

1. **熵（$S$）**：度量体系混乱程度（有序程度）的物理量，单位为 $\mathrm{J\cdot mol^{-1}\cdot K^{-1}}$。
2. **熵值大小比较**：
   - 同一物质：$S(g) > S(l) > S(s)$，气态熵最大、液态次之、固态最小；
   - 温度升高，熵增大；气体物质的量增多，熵增大；
   - 同温同压下，摩尔质量相近的不同物质，结构越复杂熵越大。
3. **熵变（$\Delta S$）的判断**：
   - 气体分子数增大（$\Delta n(g)>0$）的反应，一般是熵增反应（$\Delta S>0$）；
   - 气体分子数减小的反应，一般是熵减反应（$\Delta S<0$）；
   - 气体分子数不变的常用反应，熵变近似为零。

### 典型实例

| 反应                                         | 气体分子数变化 | 熵变                 |
| -------------------------------------------- | -------------- | -------------------- |
| $\ce{2H2(g) + O2(g) = 2H2O(l)}$              | $3 \to 0$      | $\Delta S<0$（熵减） |
| $\ce{H2(g) + Cl2(g) = 2HCl(g)}$              | $2 \to 2$      | $\Delta S\approx0$   |
| $\ce{(NH4)2CO3(s) = NH4HCO3(s) + NH3(g)}$    | $0 \to 1$      | $\Delta S>0$（熵增） |
| $\ce{N2O4(g) \xrightleftharpoons{} 2NO2(g)}$ | $1 \to 2$      | $\Delta S>0$（熵增） |

### 熵判据的局限性

体系有自发地向混乱度增加（熵增）方向转变的倾向，但同样不是绝对判据：

- 熵增过程不一定自发：如常温下冰融化是熵增的，但低于 $0\ ^\circ\mathrm{C}$ 时不会自发；
- 熵减过程也可能自发：如 $0\ ^\circ\mathrm{C}$ 以下水结冰是熵减的，却能自发进行。

## 复合判据（自由能判据）

### 吉布斯自由能

在等温、等压条件下的封闭体系中，自由能（符号 $\Delta G$，单位 $\mathrm{kJ/mol}$）的变化综合反映了焓变和熵变对自发过程的影响：

$$
\Delta G=\Delta H-T\Delta S
$$

### 判断标准

| $\Delta G$ 取值 | 反应方向         |
| --------------- | ---------------- |
| $\Delta G<0$    | 反应能自发进行   |
| $\Delta G=0$    | 反应处于平衡状态 |
| $\Delta G>0$    | 反应不能自发进行 |

### 四种焓熵组合分析

| 组合                       | $\Delta G=\Delta H-T\Delta S$ 分析 | 结论                     |
| -------------------------- | ---------------------------------- | ------------------------ |
| $\Delta H<0$，$\Delta S>0$ | 任何温度下 $\Delta G<0$            | **任何温度都自发**       |
| $\Delta H>0$，$\Delta S<0$ | 任何温度下 $\Delta G>0$            | **任何温度都不自发**     |
| $\Delta H>0$，$\Delta S>0$ | 温度足够高时 $\Delta G<0$          | **高温自发，低温不自发** |
| $\Delta H<0$，$\Delta S<0$ | 温度足够低时 $\Delta G<0$          | **低温自发，高温不自发** |

> **重点**
> 后两种情况存在转折温度：令 $\Delta G=0$，得 $T=\dfrac{\Delta H}{\Delta S}$（注意单位统一，$\Delta H$ 用 $\mathrm{kJ/mol}$、$\Delta S$ 用 $\mathrm{kJ\cdot mol^{-1}\cdot K^{-1}}$），即为自发与不自发的温度分界。

### 典型例题

**例**：$\ce{CaCO3(s) = CaO(s) + CO2(g)}\quad\Delta H=+178\ \mathrm{kJ/mol}$，$\Delta S=+169\ \mathrm{J\cdot mol^{-1}\cdot K^{-1}}$，估算 $\ce{CaCO3}$ 分解的最低温度。

**解**：$\Delta H>0$、$\Delta S>0$，属于"高温自发"。转折温度：

$$
T=\frac{\Delta H}{\Delta S}=\frac{178\ \mathrm{kJ/mol}}{0.169\ \mathrm{kJ\cdot mol^{-1}\cdot K^{-1}}}\approx1053\ \mathrm{K}\approx780\ ^\circ\mathrm{C}
$$

即温度高于约 $780\ ^\circ\mathrm{C}$ 时分解才能自发进行，这与石灰窑的实际生产温度相符。

## 注意事项

1. **自发 $\neq$ 迅速**：自发只讨论可能性与方向，不涉及速率（速率由活化能决定）。
2. **自发 $\neq$ 一定发生**：还要考虑条件（如点燃、加热只是引发手段，不改变自发性）。
3. **放热且熵减的反应低温自发**：如 $\ce{NH3(g) + HCl(g) = NH4Cl(s)}$。
4. **吸热且熵增的反应高温自发**：如 $\ce{C(s) + H2O(g) \xrightarrow{高温} CO(g) + H2(g)}$。
5. 判断方向时先看 $\Delta H$ 与 $\Delta S$ 的符号组合，再结合温度分析 $\Delta G$，不要死记结论。

# 05 · 化学反应的调控 <Badge type="warning" text="整理中" />

## 调控的基本思路

工业生产对化学反应的要求通常包括四个方面：

1. **安全性**：条件温和、易控、无危险；
2. **速率**：越快越好，缩短生产周期；
3. **限度**：转化率越高越好，原料利用充分；
4. **成本**：设备、能耗、原料价格的综合权衡。

其中**速率与限度往往是一对矛盾**：有利于提高速率的条件（如高温、增大浓度）未必有利于提高平衡转化率，反之亦然。因此实际生产条件是**综合折中**的结果。

## 工业合成氨

### 反应特点

$$
\ce{N2(g) + 3H2(g) \xrightleftharpoons{} 2NH3(g)}\qquad\Delta H=-92.4\ \mathrm{kJ/mol}
$$

特点：正反应是**放热**、**气体分子数减小**的可逆反应，且常温下速率极慢（$\ce{N2}$ 中 $\ce{N \equiv N}$ 键能大，很难断裂）。

### 各条件的选择与分析

| 条件   | 对速率的要求   | 对限度（平衡）的要求                                  | 实际选择                                    | 原因                                                               |
| ------ | -------------- | ----------------------------------------------------- | ------------------------------------------- | ------------------------------------------------------------------ |
| 浓度   | 增大反应物浓度 | 增大 $\ce{N2}$、$\ce{H2}$ 浓度，及时分离出 $\ce{NH3}$ | 及时液化分离 $\ce{NH3}$，补充原料气循环利用 | 分离 $\ce{NH3}$ 减小生成物浓度，平衡正移；循环利用提高原料利用率   |
| 压强   | 越大越快       | 越大越正移                                            | $10\sim30\ \mathrm{MPa}$                    | 压强越大转化率越高，但压强过大对设备强度、动力成本要求过高         |
| 温度   | 越高越快       | 低温有利于正移（放热反应）                            | $400\sim500\ ^\circ\mathrm{C}$              | 铁触媒的**最大活性温度**；温度过低速率太慢，过高转化率下降，取折中 |
| 催化剂 | 加快           | 不影响平衡                                            | 铁触媒                                      | 成倍提高速率，不改变限度                                           |

### 工艺流程中的关键环节

1. **原料气的制备与净化**：$\ce{N2}$ 来自空气（液化分离或与 $\ce{H2}$ 燃烧耗氧）；$\ce{H2}$ 来自水煤气或天然气重整。
2. **干燥、净化**：防止杂质（如 $\ce{CO}$、$\ce{H2S}$ 等）使催化剂**中毒**而失去活性。
3. **压缩**：将混合气体压缩至 $10\sim30\ \mathrm{MPa}$ 送入合成塔。
4. **合成**：在铁触媒催化下于 $400\sim500\ ^\circ\mathrm{C}$ 反应，单程转化率一般只有 $10\%\sim20\%$。
5. **冷凝分离**：冷却使 $\ce{NH3}$ 液化分离（沸点 $-33.5\ ^\circ\mathrm{C}$，远高于 $\ce{N2}$、$\ce{H2}$），液氨进入储罐。
6. **循环利用**：未反应的 $\ce{N2}$、$\ce{H2}$ 经压缩机重新送回合成塔，提高原料总利用率。

## 调控规律总结

> **重点**
> 分析工业条件选择问题的固定思路：
>
> 1. 先写出反应特点（吸放热、气体分子数变化、是否需要催化剂）；
> 2. 速率与限度逐条分析，指出矛盾；
> 3. 结合设备、成本、催化剂活性温度等因素说明**折中理由**；
> 4. 凡是"分离产物、循环原料"的措施，同时提高速率（反应物浓度相对增大）和限度（减小生成物浓度），是"无矛盾"的优化手段。

### 同类例证：接触法制硫酸

$\ce{2SO2(g) + O2(g) \xrightleftharpoons{} 2SO3(g)}\quad\Delta H<0$，同样为放热、气体分子数减小的反应：

- 温度选 $400\sim500\ ^\circ\mathrm{C}$（钒触媒活性温度），压强选**常压**（常压下转化率已达 $90\%$ 以上，再加压收益小于设备成本）；
- 使用过量空气（增大 $\ce{O2}$ 浓度）提高 $\ce{SO2}$ 转化率。

## 注意事项

1. 催化剂**不能**提高平衡转化率，只能缩短达到平衡的时间；
2. "加压有利于合成氨"是从限度角度说的，选 $10\sim30\ \mathrm{MPa}$ 是速率、限度、设备成本三者的折中，不是越大越好；
3. 温度选 $400\sim500\ ^\circ\mathrm{C}$ 的核心理由是**催化剂活性**，而不是平衡（平衡角度应低温）；
4. 分离液氨既促进平衡正移，又使后续反应相对加快，答题时不要漏掉"循环利用"。

# 06 · 电离平衡 <Badge type="warning" text="整理中" />

## 强电解质与弱电解质

### 电解质与非电解质

1. **电解质**：在水溶液里**或**熔融状态下能导电的**化合物**。
2. **非电解质**：在水溶液和熔融状态下都**不能**导电的化合物。

判断方法：先判断是否属于化合物，再判断水溶液或熔融态下能否导电。

### 易错举例

1. $\ce{CO2}$ 的水溶液能导电，但 $\ce{CO2}$ **不是**电解质（导电的是它与水反应生成的 $\ce{H2CO3}$，$\ce{H2CO3}$ 才是电解质）；$\ce{SO2}$、$\ce{NH3}$、$\ce{Cl2}$（单质）同理；
2. $\ce{NH3}$ 的水溶液能导电，但 $\ce{NH3}$、氨水都不是电解质，$\ce{NH3\cdot H2O}$ 是电解质；
3. 单质（如 $\ce{Cu}$、$\ce{Cl2}$）和混合物（如盐酸、氨水）既不是电解质也不是非电解质；
4. 能导电的不一定是电解质（如石墨、铜），电解质不一定能导电（如固态 $\ce{NaCl}$ 不导电）。

### 强电解质与弱电解质

| 类别     | 定义                 | 常见物质                                                                                                                                                                                                                                                   |
| -------- | -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 强电解质 | 水溶液中**完全电离** | 六大强酸：$\ce{HCl}$、$\ce{H2SO4}$、$\ce{HNO3}$、$\ce{HBr}$、$\ce{HI}$、$\ce{HClO4}$；四大强碱：$\ce{KOH}$、$\ce{NaOH}$、$\ce{Ca(OH)2}$、$\ce{Ba(OH)2}$；绝大多数盐（$\ce{BaSO4}$、$\ce{CaCO3}$、$\ce{AgCl}$ 等）；金属氧化物（$\ce{CaO}$、$\ce{CuO}$ 等） |
| 弱电解质 | 水溶液中**部分电离** | 弱酸：$\ce{HF}$、$\ce{CH3COOH}$、$\ce{HClO}$、$\ce{H2CO3}$、$\ce{H2SO3}$、$\ce{H2S}$ 等；弱碱：$\ce{NH3\cdot H2O}$、$\ce{Fe(OH)3}$、$\ce{Cu(OH)2}$ 等；$\ce{H2O}$                                                                                          |

> **易错点**
>
> 1. 溶液导电能力的强弱取决于**离子浓度**和离子所带电荷数，与电解质强弱**没有必然联系**；
> 2. $\ce{BaSO4}$ 难溶于水，导电性几乎为零，但溶解的极少部分完全电离，属于**强电解质**；
> 3. 除强酸、强碱外，考查中出现的酸碱一般视为弱酸、弱碱。

## 电离方程式的书写

1. 强电解质用"="，弱电解质用"$\xrightleftharpoons{}$"；
2. 多元弱酸**分步电离**，以第一步为主：

$$
\ce{H2CO3 \xrightleftharpoons{} H+ + HCO3-}\qquad\ce{HCO3- \xrightleftharpoons{} H+ + CO3^{2-}}
$$

3. 多元弱碱电离一步写完即可：

$$
\ce{Fe(OH)3 \xrightleftharpoons{} Fe^{3+} + 3OH^-}
$$

4. 酸式盐注意强酸酸式根要拆、弱酸酸式根不拆：$\ce{NaHSO4 = Na+ + H+ + SO4^{2-}}$（水溶液中）、$\ce{NaHCO3 = Na+ + HCO3^-}$。

## 电离平衡的建立与特征

弱电解质分子电离出离子，离子重新结合成分子的速率相等时，达到电离平衡：

$$
\ce{CH3COOH \xrightleftharpoons{} CH3COO^- + H+}
$$

平衡特征（动、等、定、变）：

1. **动态平衡**：分子电离与离子结合同时进行；
2. **速率相等**：$v(\text{电离})=v(\text{结合})\neq0$；
3. **浓度不变**：各粒子浓度保持恒定；
4. **条件改变**：平衡随之移动，建立新平衡。

> **注意**
> 电离过程一般是**吸热**的，且弱电解质的电离程度通常极小（转化率很低）。

## 影响电离平衡的因素

以 $\ce{CH3COOH \xrightleftharpoons{} CH3COO^- + H+}$（$\Delta H>0$）为例：

| 条件                      | 平衡移动方向 | 结果                                                         |
| ------------------------- | ------------ | ------------------------------------------------------------ |
| 升高温度                  | 右移         | 电离程度增大，$c(\ce{H+})$ 增大                              |
| 加水稀释                  | 右移         | **越稀越电离**，但 $c(\ce{H+})$、$c(\ce{CH3COO^-})$ 反而减小 |
| 加入冰醋酸                | 右移         | 电离程度减小（浓度越大，电离程度越小）                       |
| 通入 $\ce{HCl}$ 气体      | 左移         | $c(\ce{H+})$ 增大，$\ce{CH3COOH}$ 电离被抑制                 |
| 加入 $\ce{NaOH}$ 固体     | 右移         | $\ce{OH^-}$ 消耗 $\ce{H+}$，促进电离                         |
| 加入 $\ce{CH3COONa}$ 固体 | 左移         | 增大 $c(\ce{CH3COO^-})$，抑制电离（**同离子效应**）          |

> **重点**
> "越稀越电离"是高频考点：加水稀释促进电离、$n(\ce{H+})$ 增大，但溶液体积增大得更多，所以 $c(\ce{H+})$ 减小。若稀释相同倍数，$\mathrm{pH}$ 变化：强酸 $>$ 弱酸；稀释至相同 $\mathrm{pH}$，加水：弱酸 $>$ 强酸。

## 电离常数

### 定义与表达式

一定温度下，弱电解质达到电离平衡时，溶液中离子浓度幂之积与分子浓度之比为定值。

- 一元弱酸：$\ce{CH3COOH \xrightleftharpoons{} CH3COO^- + H+}$

$$
K_{a}=\frac{c(\ce{CH3COO^-})\cdot c(\ce{H+})}{c(\ce{CH3COOH})}
$$

- 一元弱碱：$\ce{NH3\cdot H2O \xrightleftharpoons{} NH4+ + OH^-}$

$$
K_{b}=\frac{c(\ce{NH4+})\cdot c(\ce{OH^-})}{c(\ce{NH3\cdot H2O})}
$$

### 规律

1. $K_{a}$（$K_{b}$）越大，越易电离，酸性（碱性）越强；
2. **只与温度有关**，升温促进电离，$K$ 增大；
3. 多元弱酸分步电离，$K_{a1}\gg K_{a2}\gg K_{a3}$（一般相差 $10^{4}\sim10^{5}$ 倍），酸性主要由第一步决定；

   常见弱酸酸性强弱：$\ce{H2SO3}>\ce{HF}>\ce{CH3COOH}>\ce{H2CO3}>\ce{H2S}>\ce{HClO}$

4. 由 $K_{a}$ 可比较同浓度不同弱酸的 $c(\ce{H+})$、$\mathrm{pH}$、导电能力。

## 电离度

一定温度下，弱电解质达到电离平衡时，已电离的分子数占原分子总数的百分数：

$$
\alpha=\frac{\text{已电离的分子数}}{\text{原分子总数}}\times100\%
$$

**三段式计算示例**：$25\ ^\circ\mathrm{C}$ 时，$0.10\ \mathrm{mol/L}$ 醋酸溶液中 $c(\ce{H+})=1.34\times10^{-3}\ \mathrm{mol/L}$。

$$
\alpha=\frac{1.34\times10^{-3}}{0.10}\times100\%=1.34\%
$$

$$
K_{a}=\frac{c(\ce{H+})\cdot c(\ce{CH3COO^-})}{c(\ce{CH3COOH})}=\frac{(1.34\times10^{-3})^2}{0.10-1.34\times10^{-3}}\approx1.8\times10^{-5}
$$

## 注意事项

1. 电离平衡右移，电离程度一定增大，但离子浓度不一定增大（稀释就是典型反例）；
2. 强弱电解质的划分与溶解度无关，只看**已溶解部分是否完全电离**；
3. 比较同浓度弱酸溶液中的粒子浓度，先用 $K_{a}$ 或 $\mathrm{pH}$ 确定酸性强弱，再按电离和水的电离列大小顺序；
4. 加热促进电离的同时，若溶液中还有水解等过程，要逐个分析再综合比较。

# 07 · 水的电离和溶液的 pH <Badge type="warning" text="整理中" />

## 水的电离

### 水的电离平衡

水是极弱的电解质，存在电离平衡：

$$
\ce{H2O \xrightleftharpoons{} H+ + OH^-}\qquad\Delta H>0
$$

一定温度下，$c(\ce{H+})$ 与 $c(\ce{OH^-})$ 的乘积为**水的离子积**：

$$
K_{w}=c(\ce{H+})\cdot c(\ce{OH^-})
$$

### $K_{w}$ 的特点

1. $25\ ^\circ\mathrm{C}$ 时，纯水中 $c(\ce{H+})=c(\ce{OH^-})=1\times10^{-7}\ \mathrm{mol/L}$，$K_{w}=1\times10^{-14}$；
2. $K_{w}$ **只与温度有关**：电离吸热，升温促进电离，$K_{w}$ 增大（$100\ ^\circ\mathrm{C}$ 时约为 $1\times10^{-12}$，此时纯水 $\mathrm{pH}=6$ 仍为**中性**）；
3. $K_{w}$ 对酸、碱、盐的稀溶液同样适用：任何水溶液中都同时存在 $\ce{H+}$ 和 $\ce{OH^-}$，且二者乘积恒为 $K_{w}$。

### 水的电离受抑制还是促进

| 溶液类型   | 例子                             | 对水的电离的影响 | 水电离出的 $c(\ce{H+})$（$25\ ^\circ\mathrm{C}$） |
| ---------- | -------------------------------- | ---------------- | ------------------------------------------------- |
| 酸或碱     | 盐酸、$\ce{NaOH}$ 溶液           | **抑制**         | 小于 $1\times10^{-7}\ \mathrm{mol/L}$             |
| 能水解的盐 | $\ce{NH4Cl}$、$\ce{Na2CO3}$ 溶液 | **促进**         | 大于 $1\times10^{-7}\ \mathrm{mol/L}$             |
| 强酸强碱盐 | $\ce{NaCl}$ 溶液                 | 不影响           | 等于 $1\times10^{-7}\ \mathrm{mol/L}$             |

> **提示**
> 解题时抓住：酸碱溶液中水的电离被抑制，溶液中的 $\ce{OH^-}$（酸中）或 $\ce{H+}$（碱中）**全部来自水的电离**。例如 $\mathrm{pH}=2$ 的盐酸中，水电离出的 $c(\ce{OH^-})=1\times10^{-12}\ \mathrm{mol/L}$。

## 溶液的酸碱性与 pH

### 定义

$$
pH=-\lg c(\ce{H+})
$$

$25\ ^\circ\mathrm{C}$ 时：$\mathrm{pH}=7$ 为中性，$\mathrm{pH}<7$ 为酸性，$\mathrm{pH}>7$ 为碱性。$\mathrm{pH}$ 每减小 $1$，$c(\ce{H+})$ 增大 $10$ 倍。

### 常用计算

1. **强酸、强碱**：完全电离，先算 $c(\ce{H+})$（或 $c(\ce{OH^-})$），再求 $\mathrm{pH}$。
2. **酸碱混合**：先判断谁过量——
   - 酸过量：$c(\ce{H+})=\dfrac{n(\ce{H+})_{\text{酸}}-n(\ce{OH^-})_{\text{碱}}}{V_{\text{总}}}$；
   - 碱过量：先算 $c(\ce{OH^-})$，再由 $K_{w}$ 换算 $c(\ce{H+})$；
   - 恰好中和：看产物酸碱性（强酸强碱盐 $\mathrm{pH}=7$）。
3. **稀释**：强酸（碱）稀释 $10^{n}$ 倍，$\mathrm{pH}$ 变化 $n$ 个单位（不能越过 7）；无限稀释趋近于 7。
4. **速算规律**：$25\ ^\circ\mathrm{C}$ 时强酸与强碱混合 $\mathrm{pH}$ 之和为 $14$ 且等体积，恰好完全中和（无论酸碱强弱组合，只要"强+强"）。

## 酸碱中和滴定

### 原理

用已知浓度的酸（或碱）测定未知浓度的碱（或酸）：

$$
c(\text{待测})=\frac{c(\text{标准})\times V(\text{标准})}{V(\text{待测})}
$$

（一元酸碱；多元酸碱按计量数配比调整。）

### 仪器

1. **酸式滴定管**：带玻璃活塞，盛**酸性**或强氧化性溶液（不能盛碱，碱会腐蚀玻璃活塞）；
2. **碱式滴定管**：下端为橡胶管+玻璃珠，盛**碱性**溶液（不能盛酸或强氧化性溶液，会腐蚀橡胶）；
3. 锥形瓶、铁架台、滴定管夹。

读数要求：滴定管"0"刻度在**上**，读数到 $0.01\ \mathrm{mL}$；视线与凹液面最低点相平。

### 操作步骤

1. 查漏、洗涤、润洗（滴定管用待装液润洗 $2\sim3$ 次；锥形瓶只洗**不润洗**）；
2. 装液、排气泡、调零、记录初读数；
3. 移取待测液入锥形瓶，加 $2\sim3$ 滴指示剂；
4. 滴定：左手控制活塞，右手持锥形瓶向同一方向做圆周运动，眼睛注视**锥形瓶内颜色变化**；
5. 终点判断：最后一滴使指示剂变色且**半分钟内不褪色**，记录终读数；
6. 重复测定 $2\sim3$ 次，取平均体积计算。

### 指示剂的选择

| 滴定类型                              | 恰好反应点酸碱性 | 指示剂               | 终点颜色变化      |
| ------------------------------------- | ---------------- | -------------------- | ----------------- |
| 强酸滴定强碱                          | 中性             | 酚酞或甲基橙均可     | 粉红→无色（酚酞） |
| 强酸滴定弱碱（如盐酸滴氨水）          | 酸性             | **甲基橙**           | 黄色→橙色         |
| 强碱滴定弱酸（如 $\ce{NaOH}$ 滴醋酸） | 碱性             | **酚酞**             | 无色→粉红         |
| 弱酸滴定弱碱                          | 误差大           | 一般不用中和滴定测定 | —                 |

> **重点**
> 石蕊变色不明显且变色范围宽，**不能**用作中和滴定的指示剂。

### 误差分析（读数误差，"偏高/偏低"看标准液体积 $V(\text{标准})$）

| 操作                           | $V(\text{标准})$ | $c(\text{待测})$ 结果 |
| ------------------------------ | ---------------- | --------------------- |
| 滴定管尖嘴处有气泡，滴定后消失 | 偏大             | 偏高                  |
| 滴定前俯视读数（终点平视）     | 偏小             | 偏低                  |
| 滴定后俯视读数                 | 偏小             | 偏低                  |
| 滴定后仰视读数                 | 偏大             | 偏高                  |
| 滴定管未用标准液润洗           | 偏大             | 偏高                  |
| 锥形瓶用待测液润洗             | 偏大             | 偏高                  |
| 洗涤锥形瓶后残留蒸馏水         | 不变             | 不变                  |
| 滴定过快成线、附在瓶壁未冲下   | 偏大             | 偏高                  |

## 注意事项

1. 升温促进水的电离，$K_{w}$ 增大，**纯水 $\mathrm{pH}<7$ 不代表变酸**，判断酸碱性要用 $c(\ce{H+})$ 与 $c(\ce{OH^-})$ 的相对大小；
2. 酸碱混合后若"恰好完全反应"，溶液不一定中性，要看生成的盐是否水解；
3. 水电离出的 $c(\ce{H+})=1\times10^{-13}\ \mathrm{mol/L}$（$25\ ^\circ\mathrm{C}$）的溶液可能是酸也可能是碱；
4. 滴定误差分析统一从"待测浓度 $=\dfrac{c(\text{标})\cdot V(\text{标})}{V(\text{待})}$"出发，看 $V(\text{标})$ 读数偏大还是偏小即可。

# 08 · 盐类水解 <Badge type="warning" text="整理中" />

## 盐类水解的实质

盐电离出的离子与水电离出的 $\ce{H+}$ 或 $\ce{OH^-}$ 结合生成弱电解质，**破坏了水的电离平衡**，使溶液中 $c(\ce{H+})$ 与 $c(\ce{OH^-})$ 不再相等，溶液呈现酸性或碱性。

$$
\ce{NH4+ + H2O \xrightleftharpoons{} NH3\cdot H2O + H+}\qquad(\text{显酸性})
$$

$$
\ce{CO3^{2-} + H2O \xrightleftharpoons{} HCO3^- + OH^-}\qquad(\text{显碱性})
$$

> **注意**
> 水解反应是**中和反应的逆反应**，一般为**吸热**过程，且水解程度通常**极微弱**（大部分盐仍以离子形式存在，水解方程式要用"$\xrightleftharpoons{}$"，一般不标"$\uparrow$"、"$\downarrow$"）。

## 水解规律

**口诀：有弱才水解，谁弱谁水解，谁强显谁性，越弱越水解，都弱双水解。**

| 盐的类型   | 举例                                                       | 是否水解   | 溶液酸碱性               |
| ---------- | ---------------------------------------------------------- | ---------- | ------------------------ |
| 强酸强碱盐 | $\ce{NaCl}$、$\ce{KNO3}$、$\ce{BaCl2}$                     | 不水解     | 中性                     |
| 强酸弱碱盐 | $\ce{NH4Cl}$、$\ce{AlCl3}$、$\ce{FeCl3}$、$\ce{CuSO4}$     | 阳离子水解 | 酸性                     |
| 弱酸强碱盐 | $\ce{Na2CO3}$、$\ce{NaHCO3}$、$\ce{CH3COONa}$、$\ce{Na2S}$ | 阴离子水解 | 碱性                     |
| 弱酸弱碱盐 | $\ce{CH3COONH4}$、$\ce{NH4F}$                              | 双离子水解 | 比较弱酸、弱碱的相对强弱 |

1. 弱酸弱碱盐：$K_{a}$ 大（酸相对强）则溶液呈酸性，$K_{b}$ 大则呈碱性，二者相近则接近中性（如 $\ce{CH3COONH4}$，$K_{a}\approx K_{b}$，溶液近中性）；
2. 多元弱酸根**分步水解**，以第一步为主，且水解程度依次减弱：$c(\ce{CO3^{2-}}) \gg c(\ce{HCO3^-})$；
3. 弱酸酸式盐的酸碱性要比较**电离**与**水解**两个趋势：$K_{h}>K_{a2}$ 则显碱性（如 $\ce{NaHCO3}$），$K_{a2}>K_{h}$ 则显酸性（如 $\ce{NaHSO3}$、$\ce{NaHC2O4}$）。

## 水解方程式的书写

1. 单个离子水解，用"$\xrightleftharpoons{}$"，不写气体、沉淀符号：

$$
\ce{Al^{3+} + 3H2O \xrightleftharpoons{} Al(OH)3 + 3H+}
$$

2. 多元弱酸根分步写（考试中可只写第一步）：

$$
\ce{S^{2-} + H2O \xrightleftharpoons{} HS^- + OH^-}\qquad\ce{HS^- + H2O \xrightleftharpoons{} H2S + OH^-}
$$

3. 相互促进的双水解**进行彻底**，用"="并标注气体、沉淀。典型组合：$\ce{Al^{3+}}$ 与 $\ce{CO3^{2-}}$、$\ce{HCO3^-}$、$\ce{AlO2^-}$、$\ce{S^{2-}}$；

$$
\ce{2Al^{3+} + 3CO3^{2-} + 3H2O = 2Al(OH)3 v + 3CO2 ^}
$$

$$
\ce{Al^{3+} + 3AlO2^- + 6H2O = 4Al(OH)3 v}
$$

> **易错点**
> 并非所有弱酸弱碱盐都发生双水解：$\ce{CuSO4}$ 与 $\ce{Na2CO3}$ 的反应以复分解生成 $\ce{CuCO3}$ 为主（水解是次要的），要结合题给信息判断。

## 影响水解平衡的因素

以 $\ce{Fe^{3+} + 3H2O \xrightleftharpoons{} Fe(OH)3 + 3H+}$（吸热）为例：

| 条件               | 平衡移动 | 说明                                   |
| ------------------ | -------- | -------------------------------------- |
| 升高温度           | 正移     | 水解吸热，升温促进水解                 |
| 加水稀释           | 正移     | **越稀越水解**，但 $c(\ce{H+})$ 减小   |
| 通入 $\ce{HCl}$    | 逆移     | 增大 $c(\ce{H+})$，抑制水解            |
| 加入 $\ce{NaHCO3}$ | 正移     | $\ce{HCO3^-}$ 消耗 $\ce{H+}$，促进水解 |

## 水解的应用

1. **配制易水解的盐溶液**：
   - 配制 $\ce{FeCl3}$、$\ce{AlCl3}$ 溶液：先将盐溶于较浓盐酸再稀释（抑制水解）；
   - 配制 $\ce{Na2S}$、$\ce{Na2CO3}$ 溶液：加少量 $\ce{NaOH}$ 抑制水解；
2. **加热 $\ce{Na2CO3}$ 溶液去油污**：升温促进水解，碱性增强，去油污能力增强；
3. **泡沫灭火器**：$\ce{Al2(SO4)3}$ 溶液与 $\ce{NaHCO3}$ 溶液混合发生双水解，产生 $\ce{CO2}$ 和 $\ce{Al(OH)3}$ 泡沫；
4. **净水**：$\ce{FeCl3}$、明矾（$\ce{KAl(SO4)2\cdot 12H2O}$）水解生成胶体吸附悬浮杂质；
5. **判断离子能否大量共存**：弱碱阳离子与弱酸酸式根/弱酸根因双水解不能共存；
6. **制备无水盐**：$\ce{MgCl2\cdot 6H2O}$ 等在 $\ce{HCl}$ 气流中加热脱水，防止水解得 $\ce{Mg(OH)Cl}$；
7. **判断溶液酸碱性、蒸干产物**：蒸干 $\ce{FeCl3}$ 溶液得 $\ce{Fe(OH)3}$（进而灼烧得 $\ce{Fe2O3}$），蒸干 $\ce{AlCl3}$ 同理；蒸干 $\ce{Na2CO3}$ 仍得 $\ce{Na2CO3}$。

## 溶液中离子浓度大小比较

### 三大守恒

以 $\ce{Na2CO3}$ 溶液为例：

1. **电荷守恒**：所有阳离子所带正电荷总浓度等于所有阴离子所带负电荷总浓度

$$
c(\ce{Na+})+c(\ce{H+})=c(\ce{HCO3^-})+2c(\ce{CO3^{2-}})+c(\ce{OH^-})
$$

2. **物料守恒**：各形态的碳元素之和与 $\ce{Na}$ 之比等于化学式之比 $1:2$

$$
c(\ce{Na+})=2\left[c(\ce{CO3^{2-}})+c(\ce{HCO3^-})+c(\ce{H2CO3})\right]
$$

3. **质子守恒**：水电离出的 $\ce{H+}$ 与 $\ce{OH^-}$ 数目相等（由上面两式相减消去 $c(\ce{Na+})$ 得到）

$$
c(\ce{OH^-})=c(\ce{H+})+c(\ce{HCO3^-})+2c(\ce{H2CO3})
$$

### 大小排序的解题流程

1. 先定"量"：按初始浓度写出**不水解**离子的浓度（一般排第一）；
2. 再看"水解/电离"：确定弱离子水解后生成什么粒子、消耗什么粒子；
3. 列守恒：电荷守恒、物料守恒（必要时加质子守恒）校验；
4. 比较"大小不等式"与"和差等式"两类结论。

**典型结论**（同浓度）：

- $\ce{Na2CO3}$ 溶液：$c(\ce{Na+})>c(\ce{CO3^{2-}})>c(\ce{OH^-})>c(\ce{HCO3^-})>c(\ce{H+})$
- $\ce{CH3COONa}$ 溶液：$c(\ce{Na+})>c(\ce{CH3COO^-})>c(\ce{OH^-})>c(\ce{H+})$
- $\ce{NH4Cl}$ 溶液：$c(\ce{Cl^-})>c(\ce{NH4+})>c(\ce{H+})>c(\ce{OH^-})$

## 注意事项

1. 水解方程式**不能**写"$=$"（双水解彻底的除外），不标气体沉淀符号；
2. "越稀越水解"，但稀释后所有离子浓度都减小（由水补充的 $\ce{OH^-}$/ $\ce{H+}$ 相对突出）；
3. 电离平衡右移是"促进"了粒子总数增加，水解平衡右移时弱离子浓度一定是减小的；
4. 蒸干、灼烧类题目先考虑"水解是否被促进"，再考虑产物是否分解或氧化。

# 09 · 沉淀溶解平衡 <Badge type="warning" text="整理中" />

## 沉淀溶解平衡的建立

难溶电解质（如 $\ce{AgCl}$）在水中虽有极少量溶解，溶解的部分**完全电离**，存在溶解与沉淀生成的动态平衡：

$$
\ce{AgCl(s) \xrightleftharpoons{} Ag+ (aq) + Cl^- (aq)}
$$

1. **动态平衡**：$v(\text{溶解})=v(\text{沉淀})\neq0$；
2. 条件不变时，溶液中离子浓度保持不变；
3. 改变温度、离子浓度等条件，平衡发生移动（勒夏特列原理同样适用）；
4. 一般升温使多数沉淀溶解平衡正移（溶解吸热），**例外**：$\ce{Ca(OH)2}$ 溶解度随温度升高而减小。

## 溶度积 $K_{sp}$

### 表达式

一定温度下，难溶电解质饱和溶液中各离子浓度幂之积为常数：

$$
\ce{M_{m}A_{n}(s) \xrightleftharpoons{} mM^{n+}(aq) + nA^{m-}(aq)}\qquad
K_{sp}=c^{m}(\ce{M^{n+}})\cdot c^{n}(\ce{A^{m-}})
$$

| 难溶电解质     | 溶解平衡                                                 | $K_{sp}$ 表达式                                 |
| -------------- | -------------------------------------------------------- | ----------------------------------------------- |
| $\ce{AgCl}$    | $\ce{AgCl(s) \xrightleftharpoons{} Ag+ + Cl^-}$          | $K_{sp}=c(\ce{Ag+})\cdot c(\ce{Cl^-})$          |
| $\ce{Ag2CrO4}$ | $\ce{Ag2CrO4(s) \xrightleftharpoons{} 2Ag+ + CrO4^{2-}}$ | $K_{sp}=c^{2}(\ce{Ag+})\cdot c(\ce{CrO4^{2-}})$ |

> **重点**
> 固体、纯液体不写入 $K_{sp}$ 表达式；$K_{sp}$ 与 $K$、$K_{a}$、$K_{w}$ 一样，**只随温度变化**。

### $K_{sp}$ 与溶解度 $s$ 的换算（$25\ ^\circ\mathrm{C}$，单位 $\mathrm{mol/L}$）

1. **AB 型**（$\ce{AgCl}$）：$K_{sp}=s^{2}$，即 $s=\sqrt{K_{sp}}$；
2. **$\ce{A2B}$ / $\ce{AB2}$ 型**（$\ce{Ag2CrO4}$、$\ce{Mg(OH)2}$）：$K_{sp}=4s^{3}$，即 $s=\sqrt[3]{\dfrac{K_{sp}}{4}}$；
3. **阴阳离子个数比相同**的难溶物，$K_{sp}$ 越大溶解度越大；**类型不同**的（如 $\ce{AgCl}$ 与 $\ce{Ag2CrO4}$）必须通过换算比较，不能直接比 $K_{sp}$。

**例**：$25\ ^\circ\mathrm{C}$ 时 $K_{sp}(\ce{AgCl})=1.8\times10^{-10}$，$K_{sp}(\ce{Ag2CrO4})=2.0\times10^{-12}$，比较溶解度。

- $s(\ce{AgCl})=\sqrt{1.8\times10^{-10}}\approx1.3\times10^{-5}\ \mathrm{mol/L}$
- $s(\ce{Ag2CrO4})=\sqrt[3]{\dfrac{2.0\times10^{-12}}{4}}\approx7.9\times10^{-5}\ \mathrm{mol/L}$

虽然 $\ce{Ag2CrO4}$ 的 $K_{sp}$ 更小，溶解度却更大——这就是类型不同不能直接比较的原因。

## $Q$ 与 $K_{sp}$：沉淀的生成与溶解

任意时刻的浓度商 $Q$ 与 $K_{sp}$ 比较：

| 关系       | 状态               | 现象         |
| ---------- | ------------------ | ------------ |
| $Q>K_{sp}$ | 过饱和，平衡左移   | **生成沉淀** |
| $Q=K_{sp}$ | 饱和，沉淀溶解平衡 | 无变化       |
| $Q<K_{sp}$ | 不饱和，平衡右移   | **沉淀溶解** |

### 促进沉淀溶解的方法

1. **酸溶解法**：生成弱电解质。如 $\ce{CaCO3 + 2H+ = Ca^{2+} + H2O + CO2 ^}$；$\ce{Fe(OH)3}$ 溶于盐酸；
2. **盐溶解法**：如 $\ce{Mg(OH)2}$ 溶于 $\ce{NH4Cl}$ 溶液（$\ce{NH4+}$ 消耗 $\ce{OH^-}$）；
3. **配位溶解法**：氨水溶解 $\ce{AgCl}$、$\ce{Cu(OH)2}$：

$$
\ce{AgCl + 2NH3\cdot H2O = [Ag(NH3)2]+ + Cl^- + 2H2O}
$$

4. **氧化还原溶解法**：酸浸不活泼金属时加双氧水促进溶解：

$$
\ce{Cu + H2O2 + H2SO4 = CuSO4 + 2H2O}
$$

### 沉淀的生成

1. **调 pH**：使目标离子水解沉淀，如粗盐提纯、除 $\ce{Fe^{3+}}$（调 pH 至 $3.2\sim4.2$）；含 $\ce{Cu^{2+}}$、$\ce{Fe^{3+}}$ 废水加碱调 pH；
2. **加沉淀剂**：$\ce{S^{2-}}$、$\ce{CO3^{2-}}$、$\ce{SO4^{2-}}$ 等沉淀目标阳离子；

**元素示例**

- $\ce{Ba^{2+}}$、$\ce{Pb^{2+}}$、$\ce{Ca^{2+}}$ 用 $\ce{SO4^{2-}}$ 沉淀；
- $\ce{Cu^{2+}}$、$\ce{Ag+}$、$\ce{Pb^{2+}}$、$\ce{Ni^{2+}}$ 用 $\ce{S^{2-}}$ 沉淀；
- $\ce{Mg^{2+}}$、$\ce{Ca^{2+}}$、$\ce{Fe^{3+}}$、$\ce{Al^{3+}}$ 可用氢氧化物沉淀（注意 pH 控制，防止 $\ce{Al(OH)3}$、$\ce{Fe(OH)3}$ 溶解过酸环境）；
- $\ce{Ca^{2+}}$、$\ce{Co^{2+}}$、$\ce{Ni^{2+}}$ 可用可溶性草酸盐沉淀。

### 分步沉淀

溶液中同时存在多种可与同一沉淀剂反应的离子时，**所需沉淀剂浓度最小的离子先沉淀**。

**例**：向含 $\ce{Cl^-}$、$\ce{CrO4^{2-}}$ 的混合溶液中滴加 $\ce{AgNO3}$：

- $\ce{AgCl}$ 开始沉淀所需 $c(\ce{Ag+})=\dfrac{1.8\times10^{-10}}{0.01}=1.8\times10^{-8}\ \mathrm{mol/L}$
- $\ce{Ag2CrO4}$ 开始沉淀所需 $c(\ce{Ag+})=\sqrt{\dfrac{2.0\times10^{-12}}{0.01}}\approx1.4\times10^{-5}\ \mathrm{mol/L}$

故 $\ce{AgCl}$ 先沉淀。这也是莫尔法指示终点的原理。

## 沉淀的转化

1. **一般规律**：溶解度大的沉淀容易转化为溶解度小的沉淀（$\ce{ZnS \to CuS}$、$\ce{AgCl \to AgI}$）：

$$
\ce{AgCl(s) + I^- \xrightleftharpoons{} AgI(s) + Cl^-}
$$

2. **逆向转化**：当两种沉淀溶解度相差不大时，增大另一侧离子浓度也可实现逆向转化（如浓 $\ce{Na2CO3}$ 溶液使 $\ce{BaSO4}$ 转化为 $\ce{BaCO3}$）；
3. **应用**：
   - 锅垢处理：$\ce{CaSO4}$ 转化为更疏松易除的 $\ce{CaCO3}$，再用酸溶解；
   - 矿物提取：$\ce{ZnS}$ 转化为 $\ce{CuS}$ 而富集铜；
   - 废水处理：$\ce{Pb^{2+}}$、$\ce{Hg^{2+}}$ 用 $\ce{FeS}$ 转化沉淀去除。

## 注意事项

1. $K_{sp}$ 表达式中离子浓度的幂来自**化学式中的离子个数**，不要漏乘系数；
2. 比较溶解度必须先统一为 $\mathrm{mol/L}$（注意摩尔质量换算 $\mathrm{g}/100\ \mathrm{g}$ 水 $\leftrightarrow\ \mathrm{mol/L}$）；
3. "沉淀完全"通常指离子浓度小于 $1\times10^{-5}\ \mathrm{mol/L}$，不是完全除尽；
4. 除杂调 pH 时，目标离子不能沉淀：如除 $\ce{Fe^{3+}}$ 不能用 pH 过高的条件，否则 $\ce{Cu^{2+}}$ 等也会沉淀；
5. 分步沉淀的先后看"开始沉淀所需的沉淀剂浓度"，而不是直接比 $K_{sp}$。
